# 🛡️ Secure Web Application

A security-focused web application built with **Python**, **Flask**, and **SQLite** that demonstrates secure authentication and secure software development practices.

This project was built to strengthen my software security engineering skills by implementing real-world security controls commonly used in production web applications.

---

## Features

- User Registration
- User Login
- Secure Dashboard
- Logout Functionality
- Session Management
- Flash Messages
- Responsive User Interface

---

## Security Features

- Password Hashing (Werkzeug)
- SQL Injection Prevention
- CSRF Protection
- Secure Session Cookies
- HTTP Security Headers
- Login Rate Limiting
- Custom Error Pages
- Server-side Input Validation
